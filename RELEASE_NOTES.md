StorageScope 3.1

• Filtres par nom, chemin, catégorie, taille minimale et type ; filtre par source pour les applications Windows.
• Tri numérique du plus volumineux au moins volumineux par défaut, tri inverse et tri alphabétique disponibles.
• Vue Windows des fichiers par catégorie : les 500 principaux fichiers de chaque catégorie sont retenus indépendamment du classement global.
• Icônes locales des applications Windows, avec une icône neutre si aucune image exploitable n’est déclarée.
• Taille des applications déclarée par Windows ou le launcher, complétée par l’analyse du dossier ; tailles inconnues placées en dernier.
• Filtres macOS enrichis pour les fichiers, applications et propositions de nettoyage ; ouverture des catégories en taille décroissante.
• Protections de nettoyage et fonctionnement hors ligne conservés. La distribution de test Windows reste non signée et se met à jour manuellement.
